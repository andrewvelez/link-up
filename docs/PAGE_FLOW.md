# Pages and Page-to-Page navigation flows

## Common Pages

Not all site functionality will be encapsulated into pages.  Some maybe contained by web components or modals.

### "/About"

Includes basic information about the site and PWAs in general.  This page may also include device specific instructions needed for users to install the PWA.

### "/Default" and "/" and "/Index"

The root page.  The root domain, index.html are the same as /Default.  The login portion will be implemented by a web component.  The login web component needs to be very familiar.

### "/Profiles"

This is the search results page.  It is a grid/map of profiles filtered by several criteria (facet filtering, geocells, blocklists).
