Link-up square outline mockup artwork

Square controls and containers; vermilion is used mainly for outlines and glyphs.

Original vector assets used in the accompanying Default, About, and Profiles screenshots.

brand/ - link mark in vermilion and warm white
glyphs/ - 23 standalone UI glyphs, 24 x 24 viewBox, 1.6-unit round strokes
avatars/ - four original abstract profile illustrations
maps/ - illustrative Brooklyn concept map, not real geographic data
palette.css - colors used in the mockups

SVG glyphs use currentColor. When inline, set CSS color to recolor them. When used as image files, their default color is warm gray; edit the root color attribute to change it.

Screenshots use locally installed Albert Sans. Font files are not included.
Mockup names, ages, status indicators, map circles and counts are fictional.
