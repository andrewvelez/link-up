Prove it to yourself

  1. Load this page once while the dev server is running.
  2. Install it: use the address-bar install icon, or the button in the header.
  3. Stop the server entirely.
  4. Open the installed app from your launcher. It still works, and so does everything on this page.

The cache is keyed by a version string in sw.js. Change it, reload once while the server is running, and the new shell replaces the old one on the next launch. That is your entire release process.
